# Demo2 本地运行与烟测入口

本文档用于快速回答：终端怎么启动、浏览器打开哪里、改完代码跑什么检查。

## 1. 启动开发服务器

在终端运行：

```bash
cd "/Users/lijiajun/Documents/GitHub/Li-Jiajun/物理<->数字投影/demo2-web" && npm run dev
```

双击 `demo2-web/启动Demo2.command` 时，服务启动成功后会自动打开默认浏览器。手动运行 `npm run dev` 时，终端会显示 Vite 地址。

## 2. 浏览器访问地址

打开 Chrome，访问：

```text
http://127.0.0.1:5173/
```

当前工程固定使用 `5173`。如果端口被占用，启动会报错；先关闭占用该端口的旧进程，再重新启动。

## 3. 常用检查命令

代码修改后，在终端运行：

```bash
cd "/Users/lijiajun/Documents/GitHub/Li-Jiajun/物理<->数字投影/demo2-web" && npm run build
```

通过标准：

- `npm run build` 成功生成 `dist`；
- Vite 的 `Some chunks are larger than 500 kB` 是当前已知体积警告，不影响 Demo 本地运行。

## 4. 当前烟测入口

当前主烟测以 [Demo2开发进度看板](Demo2开发进度看板.md) 的“当前烟测入口”为准。

常用页面：

- 总览：`http://127.0.0.1:5173/`
- 工厂场景：进入顶部导航“工厂场景”
- 平面运营视图：进入顶部导航“平面运营视图”
- 立面钻取：进入顶部导航“立面钻取”
- 参数录入：进入顶部导航“参数录入”
- 方案对比：进入顶部导航“方案对比”
- 报告：进入顶部导航“报告”

## 5. 如果程序已经关掉

重新运行第 1 节的启动命令即可。浏览器页面如果显示无法访问，刷新或重新打开第 2 节地址。
