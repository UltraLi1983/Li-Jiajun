Demo2 UI 风格预览

这里放了 10 个独立 HTML 预览页。你可以逐个打开看整体气质，再决定 Demo2 第一版主风格。我的默认推荐是 1 或 6，报告页可以借鉴 2 或 9。

1. 深色工业指挥舱黑蓝底、荧光青蓝、地图感强，适合作为 Demo2 主风格。 2. 高级制造业白底仪表盘白底、深蓝灰、专业克制，适合参数页和正式报告。 3. 数字孪生科技蓝蓝色渐变、透明面板、数字孪生感强，适合演示未来系统。 4. 德系工业极简黑白灰、硬线条、少装饰，强调工程理性。 5. 黑金高端老板视图深黑与金色重点，商务质感强，适合老板向路演。 6. 运营控制塔运营控制塔感觉，适合 KPI、风险、24H 峰谷和运输任务。 7. 工程 CAD 风格网格、线框、节点、坐标感强，适合 Layout 标注页。 8. Apple 式空间感柔和玻璃、圆角、空间层次，高级但工业硬度稍弱。 9. 精益咨询报告风格白底、表格、红黄绿风险，适合售前报告和咨询交付。 10. 未来全息工厂风暗色、霓虹线框、全息感强，视觉冲击最大但需克制。
