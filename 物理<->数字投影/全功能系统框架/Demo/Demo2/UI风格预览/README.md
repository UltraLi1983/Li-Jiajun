# Demo2 UI 风格预览

本文件夹用于独立查看 Demo2 第一版可能采用的 10 种 UI 方向。

## 打开方式

优先打开：

```text
index.html
```

然后逐个点击查看 10 种风格。

也可以直接打开某个单独风格文件。

## 风格清单

| 文件 | 风格 |
|---|---|
| `01-industrial-command-center.html` | 深色工业指挥舱 |
| `02-manufacturing-white-dashboard.html` | 高级制造业白底仪表盘 |
| `03-digital-twin-tech-blue.html` | 数字孪生科技蓝 |
| `04-german-industrial-minimal.html` | 德系工业极简 |
| `05-black-gold-owner-view.html` | 黑金高端老板视图 |
| `06-operations-control-tower.html` | 运营控制塔 |
| `07-engineering-cad.html` | 工程 CAD 风格 |
| `08-apple-spatial.html` | Apple 式空间感 |
| `09-lean-consulting-report.html` | 精益咨询报告风格 |
| `10-holographic-factory.html` | 未来全息工厂风 |

## 我的初步建议

主界面建议优先考虑：

```text
01 深色工业指挥舱
06 运营控制塔
```

辅助页面可以混合：

```text
07 工程 CAD 风格：Layout 标注页
09 精益咨询报告风格：售前报告页
02 高级制造业白底仪表盘：参数与专业表格页
```
