# Demo2 Web App（恢复版）

当前演示工程位于本目录；启动地址固定为 `http://127.0.0.1:5173/`。恢复过程中的旧版副本已移至 `../迁移归档/审核系统+运营系统架构-2026-10-30/demo2-web/`。

## 启动

在本目录执行：

```bash
npm install
npm run dev -- --host 127.0.0.1 --strictPort
```

也可以双击 `启动Demo2.command`。脚本在服务启动成功后会自动打开默认浏览器；重复双击时会复用已运行的 Demo2。若 5173 被其他程序占用，会明确报错。

## 检查

```bash
npm run build
node --test test/recovery-guard.test.cjs
```

PDF 在浏览器中按 300 dpi 渲染选定页；每页作为独立规划图纸，分别记录楼栋、楼层、规划单元名称、标尺和区域。原 PDF 与各页草稿保存在本机 IndexedDB，切页后返回可继续编辑。PDF 页码不会自动推定物理楼层；同一楼层若分布在多张图纸，需先对齐坐标才能合并计算。

Layout 预览框按当前 PDF 页或图片的原始宽高比自动显示横向/纵向，切页时重置视图以完整显示新页面；放大和平移仍可用于查看细节。
