# Demo2 界面布局设计说明

> 版本：`demo2-ui-layout-v0.1-2026-08-31`  
> 状态：UI 风格已锁定 / 页面布局待细化  
> 关联：`Demo2软件开发任务计划.md`、`UI风格预览/01-industrial-command-center.html`

---

## 1. UI 风格锁定

Demo2 第一版 UI 风格锁定为：

```text
1 号 UI：深色工业指挥舱
```

核心气质：

- 深色底；
- 工业感；
- 指挥舱；
- 数字孪生；
- KPI 强；
- 路径 / 区域 / 风险可视化；
- 适合老板售前演示，也能承载专业团队查看计算假设。

---

## 2. 重要边界

当前 `UI风格预览/01-industrial-command-center.html` 只用于确认视觉方向，不代表最终页面排版。

后续真实界面需要重新设计，尤其是：

- 主平面运营视图应让 Layout / 物理世界占主导；
- 参数区应作为侧边工程面板，不抢主画面；
- Baseline / Proposed 应更像方案切换，而不是普通数据卡片；
- 立面钻取应与平面视图形成明确转场关系；
- 老板视图和专业视图应分层，不在同一屏堆满信息。

---

## 3. 推荐主界面结构

主界面建议采用：

```text
顶部：客户 / 场景 / Baseline-Proposed / Supermarket Mode
左侧：对象层级 / 图层开关
中间：平面运营视图，占 60-70% 空间
右侧：选中对象详情 / KPI / 风险 / 计算假设
底部：时间轴 / 运输任务动画 / 24H 峰谷
```

示意：

```text
┌──────────────────────────────────────────────────────────────┐
│ Top Bar: Scenario / Baseline-Proposed / Supermarket / Report │
├──────────────┬───────────────────────────────┬───────────────┤
│ Object Tree  │                               │ Detail Panel  │
│ Layer Toggle │      Plane Operation View      │ KPI / Risk    │
│              │                               │ Assumptions   │
├──────────────┴───────────────────────────────┴───────────────┤
│ Timeline / Transport Task Animation / 24H Peak-Valley         │
└──────────────────────────────────────────────────────────────┘
```

## 4. 页面级布局方向

| 页面 | 布局方向 |
|---|---|
| 总览页 | 指挥舱大屏，KPI + 风险 + 方案入口 |
| Layout 标注页 | CAD / 工程标注风格，可借鉴 7 号风格，但颜色归入 1 号主系统 |
| 平面运营视图 | 中心大画布，左右工具栏，底部时间轴 |
| 立面钻取视图 | 从 StorageArea / Rack 进入，展示 Rack / Level / Lane / SkuSlot |
| 参数页 | 深色工业表单，不做白底报表风 |
| 方案对比页 | Baseline / Proposed / Stress 三方案横向对比 |
| 报告页 | 可适当借鉴 9 号精益报告风格，但保持主系统深色外壳 |

---

## 5. 设计原则

1. 物理世界优先：主画面优先展示 Layout、路线、区域、存储对象。
2. 计算可解释：所有 KPI 能追溯到输入和假设。
3. 动效有意义：动画用于表达运输任务、转场和状态变化，不做装饰性炫技。
4. 风险要醒目：红 / 黄 / 绿风险状态必须清晰，但不只依赖颜色。
5. 专业不拥挤：老板视图少而强，专业视图深而可查。
