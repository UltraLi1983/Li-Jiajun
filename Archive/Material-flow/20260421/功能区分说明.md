# 交互式循环配送模拟系统 - 功能模块划分说明

## 概述

本系统已按照前端开发的最佳实践，将代码按功能模块拆分为三个独立文件：

- **`Interactive Simulation.html`** - 页面结构层
- **`styles.css`** - 样式表现层  
- **`separate.js`** - 业务逻辑层

这种分离遵循了关注点分离原则，便于维护和扩展。

## 各模块功能职责

### 1. Interactive Simulation.html (页面结构)

**文件职责：**
- 定义页面的整体结构和布局
- 提供所有用户界面元素的骨架
- 引用外部样式和脚本资源

**具体功能：**
- HTML文档基本结构 (DOCTYPE, html, head, body)
- 页面标题和元信息设置
- 容器布局结构 (container, main-layout)
- 用户界面组件：
  - 交互说明面板
  - 模拟参数配置区
  - 操作控制按钮区
  - 统计结果展示区
  - 画布和编辑面板
  - 加载动画和提示框等辅助组件
- 外部资源引用 (CSS和JS文件)

**特点：**
- 只包含HTML标签和结构
- 无样式代码 (class除外) 和JavaScript逻辑
- 作为其他两个模块的容器

### 2. styles.css (样式表现)

**文件职责：**
- 定义页面视觉外观和布局样式
- 控制所有UI元素的显示效果

**具体功能：**
- 全局样式设置 (重置默认样式)
- 整体页面布局 (flex, grid)
- 组件样式 (面板、按钮、输入框等)
- 视觉效果 (颜色、阴影、渐变、动画)
- 响应式设计适配
- 交互状态样式 (hover, active, focus)

**特点：**
- 专门处理视觉表现
- 无业务逻辑代码
- 包含媒体查询适配不同屏幕尺寸
- 所有颜色、间距、字体等视觉相关参数

### 3. separate.js (业务逻辑)

**文件职责：**
- 实现系统核心功能逻辑
- 处理用户交互和数据操作
- 执行模拟算法和数据处理

**具体功能：**

#### 数据管理
- 全局变量定义 (layoutNodes, selectedNode等)
- 默认布局生成函数
- 导入/导出功能 (JSON/CSV格式)

#### Canvas绘制
- 画布初始化和渲染
- 工站点绘制 (不同类型不同颜色)
- 配送路线绘制
- 坐标系和比例尺处理

#### 交互处理
- 鼠标事件监听 (mousedown, mousemove, mouseup等)
- 拖拽功能实现
- 编辑功能 (双击编辑、应用更改等)
- 悬停提示功能

#### 模拟算法
- 路径优化算法实现
- 时间计算和维护窗口处理
- 随机因子模拟 (变异系数)
- 多车辆任务分配

#### UI更新
- 统计数据显示
- 路线详情展示
- 图例更新
- 加载状态管理

**特点：**
- 包含完整的业务逻辑
- 与DOM交互以更新界面
- 实现核心算法功能
- 无样式代码

## 模块间关系

- **HTML** 提供结构基础，引用 CSS 和 JS 文件
- **CSS** 依赖 HTML 的 class 和 ID 进行样式定位
- **JS** 操作 HTML 元素并使用 CSS 定义的样式类
- 三者相互协作实现完整功能，但职责明确分离
