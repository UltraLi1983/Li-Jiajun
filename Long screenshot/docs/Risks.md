# 风险与限制

状态：Phase 0 初评，影响和对策尚待样本验证。

| 风险 | 影响 | 检测与处置 |
| --- | --- | --- |
| 快速滚动导致相邻可用帧无重叠 | 中间内容永久缺失 | 多帧候选回溯；无可验证重叠即拒绝并定位时间段。 |
| 固定导航栏、浮层占据较大面积 | 错估位移、重复 UI | 时间稳定性分区；匹配只在可滚动 ROI；ROI 不确定时拒绝。 |
| 重复列表项或纯色内容 | 多个相似位移 | 比较最佳与次佳评分，跨带一致性，低纹理拒绝。 |
| 广告、动画、视频、加载占位 | 局部像素不一致或内容后来改变 | 局部变化要求稳定带唯一配准及下一帧确认；能映射内容坐标时回填，否则拒绝。变化仅在内容离开视口后发生且未录入视频时，无法恢复其像素。 |
| 聊天、信息流新增内容或页面重排 | 内容坐标不再稳定 | 用多帧周期一致性检查；标记不支持或拆分独立段。 |
| 反向滚动 | 重复拼入旧内容 | 维护已覆盖内容坐标区间；Phase 1 仅支持短距离反向后继续前进。 |
| 横向滚动、缩放、旋转、页面跳转 | 纯纵向模型失效 | 检查横向位移、画面尺寸和突变；明确拒绝。 |
| 受保护内容在录屏中不可见 | 无法还原像素 | 不尝试恢复，提示源视频中该区域不可用。 |
| 长图过高、内存或 Photos 限制 | 崩溃或导出失败 | 预估像素预算，测峰值内存；预留分段导出与文件导出。 |
| 默认缩小使小字模糊或弱纹理误匹配 | 画质或接缝准确性下降 | 保留 `--max-width 0` 全尺寸处理；用原生高分辨率录屏核验可读性和拒绝率，证据不足即拒绝拼接。 |
| iCloud 中视频未下载 | 离线导入失败 | 提示用户使视频在本地可用，不暗中进行网络处理。 |
| 录屏包含通知、账号和私密信息 | 隐私泄露 | 全程本地处理；临时帧及时清理；报告不含原始画面，导出由用户触发。 |
| 无 Xcode/真机与真实录屏素材 | 无法证明 iOS 兼容性和目标效果 | 先运行 Swift CLI 与合成数据；获得环境和同意使用的实录后再做里程碑验收。 |

## 不支持范围（首版）

多列独立滚动、任意方向画布、旋转屏幕、连续跨页面导航、无法录制的内容、连续高速滚动且视频没有重叠帧。直播视频或大面积动画页面通常无法构成静态长图。

## 尚未解决的验证问题

1. 各机型和录屏设置下的分辨率、帧率、可变帧率及压缩伪影分布。
2. Vision 配准和自定义多带匹配在列表、网页、聊天中的精度与耗时差异。
3. 实机上单张 PNG 可写出和可导入 Photos 的安全尺寸与峰值内存。
4. iOS 最低部署版本：应在取得目标设备范围后确定；不要用本机 SDK 版本推断产品最低版本。
