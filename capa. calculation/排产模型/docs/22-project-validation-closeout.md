# 项目验证关闭清单

更新：2026-10-27。范围仅为“工艺库 → 工艺路线与工站 → 标准 SA → 现场 R&R → 参数校准 → 路线产能总览”及其综合报告。逐日需求、正式排产、连续量产实绩、库存交付和批量运行总览属于后续流程，不作为本清单的关闭条件。

## 2026-10-26：内部试算闭环的关闭口径

本轮目标是完成项目验证的**内部试算闭环**，不是解除正式发布门禁。用户已确认：没有账号和授权审核能力时，正式路线、阶段物料、R&R 验收结论及对外报告都继续标记待审核或内部草稿。下方 PV-01～PV-11 的原始正式关闭条件仍保留；内部闭环的验收记录与正式关闭记录分开。

内部闭环必须同时满足以下条件，不以页面能打开或有一个数字作为通过依据：

1. 一条实际产品路线及所有参与工站的本地工艺、阶段物料引用、冻结 SA、R&R 样本和 CT/P/Q 可逐项追踪。草稿或待审核主数据能用于内部试算，但不会被称为正式发布。
2. 每个工站可选择指定 R&R 样本修订，核对设备、观察起止、时间缺口、OK/NOK、节拍与同窗 SA；验证样例与人工真实记录明确分离。短窗 R&R 不进入整周 Actual。
3. 路线计划周能力能说明所用周账、用量/份额、参数版本、工序与工站能力、瓶颈和缺项；受控资格规则未确定时，验证周能力只标“模拟/规则待定”。缺数据留空并说明位置，不补零。
4. 生成一份同源的内部综合报告，顺序为计划 SA → R&R 同窗证据 → 路线能力评价。保存所用输入/结果快照，重开旧报告不受当前草稿修改影响；版本变化生成新快照。英文/中文关键状态一致。
5. 自动回归通过，并由用户在现有产品、路线和工站完成一轮人工烟测，记录实际结果。正式发布门禁在全过程保持阻断。

### 两日推进顺序

| 顺序 | 工作 | 验收证据 |
| --- | --- | --- |
| 先做 | 核对真实路线与工站输入、R&R 归档修订、测试样例隔离；修复缺口 | 同一工站不同修订可切换，错误身份/来源有原因，正式门禁仍阻断 |
| 接着 | 固化周账与报告快照，贯通三章综合报告；缺项按工站列出 | 改草稿后旧快照可重开，新快照反映变化；短窗 Actual 保持空白 |
| 最后 | 端到端回归和人工烟测，逐条记录通过/未通过 | 全部内部闭环条件有证据，剩余正式审批与签发项明确留在正式清单 |

当前内部报告已可保存周账、SA 源窗口和所选 R&R 样本修订，重开旧报告不受当前草稿更改影响。下一项需完成报告与所选样本的验证周能力计算链，并做现有产品/路线/工站的人工烟测；PV-04/05/06 的正式资格、外推和签发规则尚未批准，不得以内部试算通过替代。

目前已有本地 SA 冻结与恢复、R&R 逐段记录和同窗对比、参数及路线周能力的条件式预览。它们是实施基础，不等于正式验收、正式周能力发布或不可变证据归档。以下任务均未关闭；勾选前须记录验证证据。

## 任务清单

### 主数据与适用范围

- [ ] **PV-01｜正式工艺路线来源与发布**（外部主数据 + 接入）：确定产品、工艺、路线版本、工序、工站及有效期的权威来源；系统读取已发布版本，保留本地草稿与正式版本的隔离。**关闭条件**：已发布路线可完整进入项目验证；未发布或错版本路线被阻止，不能靠本地草稿绕过。

  进展（2026-10-24）：第一版来源定为系统内工艺库编排，审核后发布；外部导入未来复用同一流程。现已支持草稿送审、内容变更后申请失效和正式门禁继续阻断。人工烟测已确认待审核、刷新保留、修改后重送及正式门禁四项。由于尚无账号/角色系统，送审仅为本机待审核状态，**不是审核授权或正式发布**；PV-01 仍未关闭。
- [ ] **PV-02｜阶段物料 / WIP 引用**（外部主数据 + 接入）：给各工序接入有效的阶段物料或 WIP 引用及版本，不由验证页临时编造。**关闭条件**：缺失、失效、产品或路线不匹配时显示具体工序和原因；引用齐备后相应发布阻断解除。

  进展（2026-10-24）：正式门禁现能定位缺少输出阶段物料引用的工序，并按观察周校验阶段物料有效期；已有的产品、路线、工序及 WIP 归属校验保留。尚未接入权威阶段物料来源与版本，不能视为 PV-02 关闭。

  补充（2026-10-25）：路线阶段可登记本地零件身份、工序投入/产出关联和每件产出投入量；原记录不接入正式门禁或产能计算。投入量是生产一件本工序产出所登记的投入物料数量，不是产出零件重量或批次总投料。待完成受控来源、版本、生效期和授权后才能验收 PV-02。

  进展（2026-10-25）：首版来源选择系统内建档，已能对本地物料关系做缺项检查并提交带计划生效日期的不可覆盖版本快照；路线或物料变更后显示申请过期。由于没有账号/角色及正式批准机制，所有提交仅为待审核，**不生成已发布 Stage BOM，也不解除 PV-02 阻断**。

  校验补充（2026-10-25）：正式路线的阶段物料校验按工序前后关系逐条检查产出零件号与下一工序投入零件号，并拒绝后工序引用同一前工序的旧阶段 BOM 版本；问题定位到后工序。待审核的本地提交依旧不参与正式发布判定。正反向验收仍须在可授权发布的受控版本接入后完成。

### R&R 样本与验证规则

- [ ] **PV-03｜独立 R&R 样本归档**（工程）：同一工站可保存多次独立样本，明确产品、路线版本、工序/工站、物理设备、观察起止、记录来源及样本版本；班次名称为可选历史备注。**关闭条件**：新样本不覆盖旧样本；可按身份重开、核对并引用指定样本；记录修订可追溯。

  进展（2026-10-26）：本地多样本与修订归档保存输入快照和产品、路线版本、工序、工站、设备及观察窗口；可重开指定修订，验证样例单独标记。用户此前已确认 v1、v2 和新样本空状态可切换。本轮移除班次名称必填，旧文字保留为历史备注；输入变化后试算引用自动失效。尚未建立正式证据库或授权签发，不用于正式周能力；PV-03 仍未关闭。
- [ ] **PV-04｜样本资格与适用性**（业务定规 + 工程）：确定完整度、观察时长、设备/班次/产品适用范围、证据和代表性门槛，区分“时间账完整”与“可外推验收”。**关闭条件**：系统逐项给出合格/不合格原因；不合格样本仍可做同窗分析，但不得用于正式验证周能力。

  进展（2026-10-26）：归档表逐版本显示时间账完整度、缺失时段/生产数量与验收资格状态。验证样例不可用于正式验收；完整的人工样本仍仅显示“规则待定”。分时段明细由保存时的标准 SA 自动划分，分钟按交集计算；跨时段生产段数量不比例分摊，但整窗 OK/NOK 有效，不因未分时段而阻断样本。旧班次文字仅作历史备注。观察时长、设备适用范围、证据充分性和代表性尚无受控规则，不能自动判为合格。待定规则及首版建议见 `docs/23-rnr-qualification-decision-record.md`。
- [ ] **PV-05｜验证周能力计算**（业务定规 + 工程）：明确标准 SA 周账与合格 R&R 样本如何外推到同一路线版本、同一计划周及各工站/工序，避免计划损失与实跑损失重复扣减。**关闭条件**：给出可复核的周能力、瓶颈、输入版本与计算过程；缺站、缺周账或样本不适用时结论留空并指出缺项；不把短窗样本称为整周 Actual。
  本轮已加入本地损失采纳确认、计划动作超时入账及按生产时间比例稀释；平稳日只带入已设置动作的超时损失，生产中异常照常参与。修改计划或实跑段后须重新确认。样本资格、确认人授权、适用周与独立损失参数版本仍待完成，不能据本地试算关闭 PV-05。
- [ ] **PV-06｜验收标准与签发**（业务定规 + 工程）：确定通过阈值、有效期、重新验证触发条件及授权角色；记录采用的样本、确认人、时间、证据和结论。**关闭条件**：未获授权只能显示“模拟/待确认”；正式通过可追溯，依据变更后旧结论不被静默改写。

### 报告与可复核性

- [ ] **PV-07｜报告输入快照**（工程）：锁定用于一次结论的冻结 SA、工站周账、CT/P/Q、路线/需求版本、R&R 样本、计算口径版本及生成时点。现有本地自动保存/恢复不算此项完成。**关闭条件**：改动任一输入后生成新版本，旧报告仍能按原输入重现；缺输入不得被渲染为 0。

  进展（2026-10-26）：路线周计划报告现可保存本地、不可覆盖的双周计算输入快照，包含工站能力计算输入、用量/份额、路线版本、需求来源记录 ID 和生成时点；重开时按所存输入重新计算，当前参数变化不会改写旧结果。尚未保存综合报告的冻结 SA 原始时间段、指定 R&R 修订和计算口径版本，因此 PV-07 仍未关闭。操作见 `docs/work-instructions/27-local-route-report-snapshot.md`。

  补充（2026-10-27）：新生成的内部综合报告快照现另外封存各工站的 SA 冻结源窗口及当前草稿时段、所选 R&R 样本原始修订、计算口径版本，并在报告中提供可展开的逐段明细。修改源草稿后重开旧快照仍显示保存时证据；旧快照缺少原始资料时明确提示。周能力仍按快照内周账及有效参数输入重算，所选 R&R 修订只作为同窗证据，不会自动替换 ML 依据。尚需端到端人工验收及受控资格规则，PV-07 不据此正式关闭。

  口径补充（2026-10-26）：当前双周页已将前一周标为“对照周”，避免把仅凭自然日期形成的计划页称为历史实绩；目标周必须从周一开始。报告来源选择与历史观察窗口定义见 `docs/21-report-inputs-and-completeness.md`，尚未接入当前报告。
- [ ] **PV-08｜产能与验证综合报告**（工程）：按“计划 SA → R&R 同窗证据 → 路线能力评价”输出同一份报告，HTML 可作为首版，不要求先做 PDF。**关闭条件**：可选择产品/路线版本与样本，显示工站和工序范围、观察窗口、周能力及模拟/正式状态；三章的时间和证据口径不混用；数据不齐时列明原因。

  进展（2026-10-26）：路线周报告入口已加入“项目验证 R&R / 批量连续实绩”依据选择。项目验证可逐工站选择归档样本修订并在报告附页显示观察窗口、同窗计划/实际生产分钟、OK/NOK、时间账与资格状态；未选择的工站列缺项，快照保存所选证据摘要。样本不会直接改写计划 Best case / Most likely，也不填入整周 Actual。批量连续实绩账尚未接入，选中时阻止生成。原始 SA/R&R 证据未整体封存，三章版式与计算链尚未贯通，PV-08 仍未关闭。

  补充（2026-10-27）：报告已可展开查看所存 SA 源窗口及 R&R 修订原始时段；计划周逐日 SA 和路线能力仍分别展示。验证周能力尚未采用经资格确认的指定样本形成独立结论，报告仍标内部草稿，PV-08 尚未关闭。
