# R&R 本地独立样本归档 WI（首版）

## 适用范围

本功能保存多次 R&R 的本地证据草稿。它不判定样本资格，不签发参数，也不把验证样例当作现场数据。正式验收仍需 PV-04 至 PV-06 的规则和授权。

## 操作

1. 在「现场 R&R 跟踪」选择产品、路线、工序和工站，录入实际时间段及节拍样本。
2. 打开「参数校准与验证」中该工站的明细，找到「R&R 独立样本归档」。填写本次实际使用的**物理设备编号**，点击「归档为新样本」。无需填写班次名称。若当前是系统验证样例，归档行会明确标记「验证样例 · 非现场」。
3. 点击「开始新样本」会清空当前工站的实跑和节拍草稿，保留计划 SA 及已归档版本。再录入第二次 R&R 并归档；两次样本应分别出现在列表中。
4. 点击任一版本的「重开用于试算」可将它的输入载入当前草稿，当前工站的 Best case 与实跑对比会显示引用的样本和修订。输入发生变化后，该引用自动失效，继续按实时草稿试算。修改后点击「保存当前样本修订」，旧版本保留。刷新页面后仍可按产品、路线版本、工序和工站重新找到并重开；刷新后如需继续修订，先重开对应版本。

## 核对点

- 同一工站的新样本不会覆盖旧样本；同一样本的修订号递增，旧修订可重开。
- 不同产品、路线版本、工序和工站的样本不混列。新的实跑观察应开始新样本；对同一次观察的记录进行纠正时，可保存修订，旧版本保留。物理设备与原样本身份不一致时，系统会要求新样本。
- 旧版归档中的班次名称和班段保留为历史备注，不推断为真实班组，也不作为整窗资格门槛。
- 样本仅为本机草稿；任何归档行均不代表“可用于正式验证周能力”。
- 归档表的「时间账」检查观察窗内计划与实际覆盖；「验收资格」另列。完整的人工样本仍显示“规则待定”，因为观察时长、设备适用范围、证据和代表性规则尚未批准；验证样例显示不可用于正式验收。
- 归档行可展开「分时段明细」：按保存时的标准 SA 自动划分时段，计划/实际分钟按时间交集计算。OK/NOK 仅对完整落在一个时段的生产记录求和；跨时段数量不按时间比例猜测，时段内显示未分配，整窗 OK/NOK 仍有效，不因此阻断整份样本。
- 已归档内容保存在本地数据库中，但当前没有授权审核或不可变服务器证据库。PV-03 仍须完成正式证据归档与人工验收后才能关闭。
