# 阶段物料资料提交待审核 WI（首版）

## 适用范围

项目验证的首版阶段物料/BOM 来源采用系统内建档。路线阶段的零件身份和投入/产出关联先保存在本地草案；本 WI 只将这份草案连同路线版本、计划生效日期及内容快照提交为**待审核**资料。当前没有账号/角色系统，任何本地提交都不等于批准或发布，不解除 PV-02 门禁。

## 提交

1. 在“工艺路线与工站”选定产品及路线，完成每道工序的产出身份、前后序投入关联，以及已知的其他投入物料和每件产出投入量。
2. 核对“阶段物料资料待审核”中的缺项。缺少产出、前后序关联或存在失效投入关联时，不能提交。
3. 填写计划生效日期；有确定的结束日期时填写计划失效日期。勾选“当前路线的产出身份和全部投入物料已录全”，再点击“提交物料资料待审核”。这项勾选仅是录入者的完整性声明，不是审核授权。
4. 提交后核对本地版本 `v1`、提交时间和“待审核”状态。相同内容与日期不能重复提交。

## 变更与复核

- 提交时会保存产品、路线版本、工序关键属性、零件身份和投入关联的内容快照；后续修改不会覆盖旧版本。
- 若提交后修改路线或物料，状态显示“内容已变更 · 需重送”。补全后再次提交生成 `v2` 等新版本；旧申请保留供追溯。
- 计划日期、零件号、每件投入量及单位必须与未来受控 BOM 一致。系统当前不会自动把本地投入量用于产能计算，也不会依据本地提交生成正式 Stage BOM。
- PV-02 的关闭仍需授权审核机制、生效版本读取及缺失/错产品路线/失效/不衔接的正反向验收；路线或工艺草稿门禁继续独立生效。
