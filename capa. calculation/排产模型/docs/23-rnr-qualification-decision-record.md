# PV-04 R&R 样本资格规则待定项

本文件记录尚未批准的业务门槛；当前代码仅判断同窗时间覆盖、生产段数量有效性与验证样例隔离。时间账完整不代表可用于正式验证周能力。

| 规则项 | 首版建议 | 尚需确认的边界 |
| --- | --- | --- |
| 最短观察 | 至少覆盖一个完整的标准生产日（当前通常为 24 小时） | 跨班、非排班时段及 48 小时样本如何计入 |
| 身份适用 | 产品、路线版本、工序、工站、物理设备和观察窗口与验证对象一致；班次名称不构成样本身份 | 同工站换设备是否可复用；是否另需班组维度的专项分析 |
| 生产数量与节拍 | 生产段 OK/NOK、每循环件数有效；节拍样本按已设规则排除停线值 | 最少有效节拍样本数及异常值复核口径 |
| 异常证据 | 异常段记录来源/证据引用；估算段单独标识 | 哪些异常允许估算及可接受证据类型 |
| 代表性 | 样本覆盖拟验证的产品、设备和运行状态 | 由系统字段自动判定的阈值，以及是否需要授权人工复核 |

规则批准前，人工样本即使时间账完整也保持“规则待定”；系统验证样例始终不能进入正式验收。跨标准 SA 时段的整窗 OK/NOK 仍可用于整窗判断，分时段件数未知仅为明细限制。不得在未批准规则下自动生成“合格”结论。
