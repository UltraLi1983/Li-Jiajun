    边界规则

    important
    Detailed R&R mode 的界面不应超过 48H。超过 48H 后，不再逐块跟踪每个事件，而是切换到周/月级粗略模拟。
    Detailed mode = station timeline + planned event + actual event + cycle check + output tracking
    Rough simulation = breaks per shift/day + setup per week/month + maintenance frequency + average abnormal profile
