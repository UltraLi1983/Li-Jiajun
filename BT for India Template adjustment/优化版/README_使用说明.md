# 印度商务签证材料优化包

## 推荐用法

1. 打开 `01_结构化录入/印度商务签证_信息采集主表.xlsx`。
2. 只填写黄色单元格，日期统一使用 `yyyy-mm-dd`。
3. 查看 `09_一致性检查`，处理所有“待填写 / 日期错误 / 有效期不足”。
4. 双击根目录中的 `生成签证文档.command`。
5. 在 `04_生成结果` 中检查生成的 Word 文件；确认后签字、盖章并转 PDF 或打印。

## 文件夹说明

- `01_结构化录入`：Excel 唯一数据源和 PPTX 可视化编辑/预览版。
- `02_自动生成`：从 Excel 生成 Word 的程序。请勿随意改变 Excel 的字段 ID 或工作表名称。
- `03_官方原始模板`：从印度驻华使馆网站下载的官方 Checklist 和 Simplified Proforma。
- `04_生成结果`：自动生成的派遣函、邀请函、行程单、简历、信息便签和 Proforma 副本。

## 关于 PPTX

PPTX 的每个黄色文本框都可直接编辑，适合快速整理文案和预览版式，但它不是正式递交文件。正式提交应使用 Word/PDF/打印件，并遵循 agency 和签证中心对签字、盖章、原件和彩色单面打印的具体要求。

## 重要限制

- Excel 中尚未录入真实个人及行程信息，因此当前生成结果包含 `<<字段名>>` 占位符。
- Proforma 的自动生成文件是基于 agency 提供的 Word 版制作的工作副本；正式递交前应与 `03_官方原始模板` 中的官方 PDF 逐项核对。
- 印度使馆/签证中心可能要求补充材料。最终版本须由公司、agency 或受理中心确认。
- 官方核对网址：https://www.eoibeijing.gov.in/page/business-visa-sports-visa/
