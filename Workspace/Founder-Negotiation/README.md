## 使用原则

- 先确认角色、责任、价值和风险，再讨论股权比例。
- 区分“联合创始人”和“职业经理人”，两种身份对应不同的薪酬、控制权和退出安排。
- 股权比例、治理权、经济权与岗位权责分别设计，避免只用一个百分比解决所有问题。
- 所有承诺应落实为可验证的职责、里程碑、投入期限和违约后果。
- 本材料是商业讨论稿，不构成中国或其他法域的法律、税务或投资意见；正式签署前应由执业律师和税务顾问审核。
