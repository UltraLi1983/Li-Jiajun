# ppt-from-markdown

将结构化 Markdown 文档转换为 16:9 的多页 PowerPoint 演示文稿。设计灵感来自海报风格：温暖的米白色背景，精细的排版，克制的色彩点缀。

## 设计原则

- **色调**: 米白/暖灰背景 (`#F4EFEA`, `#E8E2D9`)，深灰色文字 (`#2C2C2C`)，点缀色用暖金/深蓝
- **排版**: 中文使用衬线字体（Noto Serif SC 或 SimSun），英文/数字使用无衬线字体（Inter 或 Arial）
- **留白**: 充分的呼吸空间，不拥挤
- **信息层级**: 通过字号、字重、颜色区分层级，不使用过多装饰
- **照片**: 在讲师简介页预留照片占位区，不嵌入实际图片

## 幻灯片结构（基于输入内容自动生成）

### 通用结构
1. **封面页** — 标题、副标题、讲师名、关键标签
2. **讲师简介** — 文字介绍 + 右侧照片占位框（标注"请在此处插入照片"）
3. **核心资历** — 逐条列举
4. **职业经历** — 时间线形式
5. **课程体系一览** — 4个Level概述
6. **各Level详情页** — 每个Level一页
7. **课程组合建议** — 套餐表格/卡片
8. **时间安排 & 价格参考** — 表格形式
9. **项目案例库** — 表格
10. **总结页 + 感谢页**

### 细节要求

- 幻灯片尺寸严格 16:9（13.333" x 7.5"）
- 每页顶部有标题栏（深色背景 + 金色点缀线）
- 底部有页码（"X / 总数"）
- 底部有细装饰条
- 照片占位框使用虚线框效果（浅灰背景 + 居中图标文字）
- 表格使用交替行背景色
- 关键数据/数字使用强调色

## 实现方式

使用 `scripts/gen_ppt.py` 脚本生成 PPT。该脚本已封装了所有设计细节。

调用方式：
```bash
python3 <skill-path>/scripts/gen_ppt.py <markdown_path> <output_path>
```

如果用户提供的 markdown 内容不在本地文件系统中，先将内容写入临时文件再调用脚本。

脚本会自动读取 markdown 内容并生成对应 PPT。
