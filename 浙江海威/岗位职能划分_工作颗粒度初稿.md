# 各岗位职能划分（工作动作级初稿）

依据所提供的四份 JD 整理，并根据后续讨论加入“物流规划”拟设岗位。每条按“动作 → 可核验产出”表述；“主责”表示组织完成并对结果负责，“执行”表示按已批准的计划或制度操作，“协同”表示提供输入、确认或配合。以下是分工建议，不替代岗位授权、审批制度。源文件的模板残留与空白项见末尾。

## 一、跨部门主责边界

| 工作对象 | 主责岗位 | 交接与边界 |
|---|---|---|
| 订单需求转生产计划 | 计划物流经理定策略；生产计划主管审核排程；计划员编制、下达、跟踪 | 销售/项目提供需求；生产确认产能；采购承接采购需求。计划部门不代替采购签约。 |
| 采购需求转供应商交付 | 采购总监定策略；采购主管管执行；项目采购管新项目导入；采购员管日常采购 | 计划提供数量和到货节点；质量负责质量判定；仓库负责实物收货与账务。 |
| 物料实物与库存 | 仓库主管统筹；仓库组长调度；仓管员收发存盘；统计文员管单据与报表 | 采购跟催供应商，不替代仓库验收；计划分析齐套与库存策略，不替代实物保管。 |
| 工厂效率、标准工时、布局 | 工业工程部高级经理主责；助理测量、汇总与跟进 | 生产提供现场条件，财务使用工时数据，计划使用产能数据。IE 不代替生产执行排程。 |
| 信息系统与数据技术 | 信息经理统筹；各工程师按网络、安全、开发、ERP、PLM 分系统负责 | 业务部门定义业务规则与数据含义；IT 负责配置、开发、运维和技术控制。 |
| 物流规划与运输交付 | 拟设物流规划岗定义场地、运力、包装、实物流动作及系统指令；计划物流经理负责运营结果；计划员调度跟踪；仓库与驾驶员执行 | 物流规划岗制定并评价作业方案，运营岗按指令执行和反馈偏差；货物异常由现场即时取证上报。原 JD 尚未单列物流规划岗。 |

## 二、信息部

来源：《信息部-部门职责及岗位说明书260318.xlsx》各岗位同名工作表，第 2–16 行。

### 信息经理｜信息化总体责任人

1. 主责：收集各工厂年度系统需求，形成集团信息化项目清单、优先级、预算与年度计划 → 年度信息化工作目标。
2. 主责：制定 ERP、MES、OA、网络、安全等统一建设及运维标准，审查跨工厂重复建设 → 标准与项目立项意见。
3. 主责：按系统可用性、告警、巡检、备份和恢复结果评估运行风险，安排整改 → 月度运行报告、灾备方案。
4. 主责：对跨工厂项目确认范围、里程碑、资源、成本、验收条件，主持阶段评审 → 项目计划、验收记录。
5. 主责：批准信息安全策略和应急预案，组织 TISAX/ISO27001 审核及整改闭环 → 审核资料、整改台账。
6. 主责：编制 IT 预算，评估供应商服务与合同履约，组织团队招聘、培训和绩效管理 → 预算、供应商考核、人员计划。
7. 协同：将生产、物流、财务、销售需求转为 IT 方案或排期，并协调总部与工厂资源 → 需求池及响应记录。

### 网络及信息安全工程师｜网络与安全技术主责

1. 主责：维护总部、国内外工厂 WAN、办公网和工控网拓扑、地址与设备配置 → 网络拓扑及配置台账。
2. 执行：配置交换机、路由器、防火墙、SD-WAN 等，变更前验证、变更后复核 → 变更记录与回退方案。
3. 主责：监测链路与设备告警，定位中断、拥塞、时延，恢复后复盘 → 故障单、根因报告。
4. 主责：部署并维护 EDR、DLP、堡垒机和安全策略，核对覆盖范围与设备在线状态 → 安全策略/资产台账。
5. 主责：组织漏洞扫描、渗透测试，分级派发修复任务并验证闭环 → 漏洞台账与复测证据。
6. 主责：准备 TISAX 审计技术证据；组织安全事件取证、隔离、恢复和演练 → 审计资料、应急记录。
7. 执行：盘点软件授权与未授权安装，开展员工安全培训及钓鱼测试 → License 台账、培训记录。

### 软件工程师（C#／U9C）｜应用开发主责

1. 主责：澄清 U9C 二次开发需求、输入输出与验收条件 → 开发任务与技术方案。
2. 执行：开发 UBF 单据、表单、插件与功能扩展，完成测试 → 代码、测试记录。
3. 执行：开发财务、库存、生产等报表，核对字段口径与业务数据 → 报表及字段说明。
4. 主责：开发维护 U9C 与 MES、WMS、OA、PLM 的接口，处理同步失败 → 接口配置、故障记录。
5. 协同：为 ERP 运维提供复杂技术问题排查和关键用户使用培训 → 问题单、培训材料。
6. 主责：维护代码规范、版本、发布计划和技术文档，先测试再上线 → 发布记录、知识库。

### ERP 运维工程师｜U9C 财务与供应链应用主责

1. 主责：处理总账、应收应付、固定资产、成本、采购、销售、库存模块业务问题 → 问题单与处理结果。
2. 执行：保障月结、年结，核对关键流程是否可运行，及时升级阻断问题 → 结账支持记录。
3. 主责：为新工厂或新模块做需求调研、流程配置、测试和用户培训 → 实施方案、上线验收。
4. 主责：分析工厂流程差异，提出并落实跨工厂标准化方案 → 流程优化方案。
5. 主责：接收区域运维升级的二线问题，定位根因、协调开发、验证修复 → 闭环问题单。
6. 协同：排查 U9C 与 MES、WMS、OA 的业务数据不一致；指导区域运维专员 → 差异清单、培训记录。

### PLM 运维工程师｜华天 Inforcenter PLM 技术主责

1. 主责：维护账户、角色、权限、组织、流程与生命周期配置 → 配置台账、权限记录。
2. 主责：依据业务部门已确认的 APQP 阶段、交付物和评审节点配置模板 → 模板配置与验收记录；业务内容由业务部门确认。
3. 主责：管理 APQP 模板版本，测试变更、发布生产并通知项目团队 → 版本记录、发布通知。
4. 执行：处理用户操作、权限、流程和后台数据故障 → 工单与根因记录。
5. 协同：支持 BOM、物料主数据、ECN 流程；业务数据责任归属研发/工艺 → 数据异常清单。
6. 主责：监控 PLM→ERP/MES 接口、排查同步失败并校验一致性 → 接口日志、修复记录。
7. 执行：完成数据库查询、备份恢复、运维手册及用户培训 → 备份记录、知识库。

## 三、工业工程部

来源：《工业工程部-部门职责及岗位说明书260320.xlsx》两张岗位工作表，第 2–18 行。

### 工业工程部高级经理｜效率与改善主责

1. 主责：制定年度及中长期 IE、精益、智能制造规划，确定改善项目、责任人和目标 → 年度 IE 计划。
2. 主责：测算人均效率、OEE、线平衡、制造成本，筛选瓶颈与改善机会 → 效率/成本诊断。
3. 主责：批准并推进省人化、自动化、快速换型和流程再造项目 → 项目方案、收益复核。
4. 主责：规划产线布局、物流路线、工位和新项目导入的 IE 方案 → Layout、产能与工位方案。
5. 主责：组织生产、设备、质量、工艺等部门执行改善并验收成效 → 改善台账、验收记录。
6. 主责：建立并核定工时、C/T 等数据口径，向财务、计划提供正式数据 → 标准工时/C/T 数据。
7. 协同：指导车间使用 5S、目视化、价值流等方法，解决现场效率问题 → 方法标准、现场改善结果。

### 工业工程部助理｜测量、统计与现场跟进执行

1. 执行：采集产品 C/T 原始数据，核对样本、工序与版本，按月汇总发送 → C/T 明细及月报。
2. 执行：对指定产品开展 C/T 复测和改善前后对比，提交优化建议 → 单品 C/T 分析表。
3. 执行：巡查现场七大浪费，记录问题、责任人、预计收益和实施状态 → 改善提案台账。
4. 协同：参与 5S、产能提升、精益项目现场实施，拍照或记录验证结果 → 项目跟进记录。
5. 执行：组织改善会议，分发待办并追踪关闭 → 会议纪要、待办清单。

## 四、采购部

来源：《采购部-JD更新20260430.xlsx》同名岗位工作表，优先采用各岗位左侧独立填写的职责内容；采购主管同时参照“采购主管”旧版工作表。右侧重复的采购总监模板内容不作为低层岗位职责。

### 采购总监｜采购策略、供应商体系与重大风险主责

1. 主责：按业务计划和品类支出制定年度/中长期采购策略、预算与降本目标 → 采购战略与品类策略。
2. 主责：分析关键原料价格、供需和供应风险，确定单一/多源及应急策略 → 市场与风险分析。
3. 主责：建立寻源、准入、谈判、合同、绩效和合规制度 → 采购制度及授权边界。
4. 主责：审定关键供应商选择、重大谈判和战略合作，建立核心供应商资源池 → 决策记录、合同。
5. 主责：建立 QCDS 评价、分级和退出机制，审查年度降本与 TCO 成果 → 供应商评审、降本台账。
6. 主责：监督采购计划执行、重大断供处置、P2P 流程和数字化工具应用 → 交付风险及整改报告。
7. 主责：管理采购团队、费用预算和跨部门重大协同，向管理层汇报 → 团队绩效、采购经营报告。

### 采购主管｜子公司采购运营与执行监督主责

1. 主责：把集团采购策略拆成子公司品类、交期、降本与人员任务 → 月/周采购任务表。
2. 主责：审核采购申请、供应商选择、询比价、合同和订单过程是否符合授权 → 审核记录。
3. 主责：监控供应商交付和缺料风险，组织采购员处理延误并升级重大风险 → 交付预警台账。
4. 主责：组织子公司供应商评估、合同执行和绩效复盘，提出准入/淘汰建议 → 供应商评估记录。
5. 主责：检查采购降本、预算和部门指标的完成情况，组织纠偏 → 采购月报、改善清单。
6. 主责：安排采购团队工作、培训和日常管理；与计划、仓库、质量、财务对齐供需 → 分工表、会议纪要。

### 项目采购｜新项目供应商导入与交样节点主责

1. 主责：依据新项目物料、技术和进度要求寻找候选供应商 → 候选清单、寻源记录。
2. 执行：制作成本模型，分析报价构成并与项目组对齐目标成本 → COST MODEL、报价比较。
3. 主责：组织保密等前期协议签署、供应商走访、可行性和风险评估、现场审核 → 准入资料。
4. 主责：分解新零件开发与交样节点，跟踪供应商进展并对逾期预警 → 项目采购节点表。
5. 执行：向供应商传递客户特殊要求，核对接收与理解情况 → 要求传递记录。
6. 执行：提交 PLM 相关采购文件并校验版本、准确性；签订单项合同、跟进付款 → 文件记录、合同/付款状态。
7. 协同：组织供应商参与项目技术沟通；技术判定由项目/研发/质量负责 → 问题与决策纪要。

### 采购员｜日常订单、交付与对账执行

1. 执行：接收已批准采购需求，核对物料、数量、交期、供应商及价格条件 → 采购需求核对记录。
2. 执行：开展询比价、按授权签订单项合同并下达采购订单 → 比价记录、合同、订单。
3. 执行：跟催供应商生产与发货，更新预计到货时间，向计划/仓库同步缺料风险 → 到货跟踪表。
4. 执行：处理价格、数量、交期、单据等采购异常；权限外或断供风险及时升级 → 异常闭环单。
5. 执行：核对订单、收货、发票，编制对账与付款申请 → 对账单、付款计划。
6. 执行：落实已批准的降本方案，维护供应商日常沟通并向主管报告绩效 → 降本记录、供应商反馈。

### 采购助理｜岗位定义待确认

原工作表标题为“采购助理”，但岗位字段写“采购主管”，职责与采购总监/主管重复。**不能据此把战略、合同审批或供应商决策权分给采购助理。**若确有该岗，建议先由采购主管确认是否承担询价资料整理、订单录入、到货信息更新、对账材料整理和档案归集；在确认前，这些仅为待讨论的拟议动作，不视为原 JD 既定职责。

## 五、计划物流部与仓库

来源：《9、计划物流部-部门职责及岗位说明书模版(合并)260408.xlsx》各岗位同名工作表，第 2–49 行及仓储岗位第 2–16 行。

### 物流规划（拟设，未来纳入数字化团队）｜实物流系统设计与评价主责

当前 JD 未单列该岗；以下是根据业务方向提出的目标职责，须与现有计划物流经理、仓库主管和信息团队重新划定授权。

1. 主责：按订单结构、物料特性、产线节拍和流量，设计厂内收货、存储、补料、转运、发运的实物流路径 → 物流网络/动线图、节点能力表。
2. 主责：规划仓库与现场的场地、库位、暂存区、月台、通道和装卸设施，测算峰值占用与扩容条件 → 场地与库容方案。
3. 主责：测算厂内搬运、厂车及外部承运运力，设计运输频次、批量、路线、车型、装载和应急方案 → 内外部运力与运输方案。
4. 主责：按产品、客户和运输条件定义包装形式、单元载量、防护、循环器具与标签追溯规则 → 包装规范、器具配置和单件物流成本模型。
5. 主责：把实物流动作定义成系统可下发的任务：触发条件、对象、数量、位置、时间窗、优先级、执行人/设备、完成回执与异常码 → 物流任务与事件数据模型。
6. 主责：与信息团队定义 ERP/MES/WMS/PLM 等系统的物流数据交接、接口和状态更新规则，确保动态量化信息能驱动收、存、拣、补、运、交接动作 → 系统需求、接口规则、测试用例。
7. 主责：建立实物流评价方法，比较计划指令与现场执行的时效、行走/运输距离、装载率、场地利用率、包装损耗、成本及异常 → 物流绩效看板与改善清单。
8. 主责：在订单波动、产线调整、包装变更或系统改造时进行仿真/试运行、现场验证与方案迭代 → 试运行记录、方案版本及收益复核。

**交接边界：**物流规划定义“物料应该怎样移动、系统何时给谁发出什么量化指令、结果如何评价”；计划、仓储、运输岗位负责日常资源安排、任务执行、异常反馈与运营达成。物流规划对方案和指标口径负责，计划物流经理对当期交付结果负责，信息工程师对技术实现和系统运行负责。

### 计划物流经理｜供需平衡、交付、库存与物流总体责任人

1. 主责：组织销售、生产、采购形成月/周滚动需求与供需平衡决策 → 需求计划、S&OP 会议纪要。
2. 主责：审定主生产计划、物料计划、备货和排程，协调跨厂产能及通用设备资源 → 批准的计划和资源方案。
3. 主责：监控订单交付、物料短缺、产能瓶颈，确定升级和应急方案 → 交付风险台账。
4. 主责：设定安全库存、库存周转、呆滞品处置原则；监督仓库收发存盘与批次追溯 → 库存策略及月报。
5. 主责：确认物流规划方案的运营约束，管理第三方物流服务履约与当期运输成本；场地、运力、包装及指令方案由拟设物流规划岗牵头定义 → 服务考核、运营反馈。
6. 主责：编制部门预算、目标与绩效，推动 ERP/WMS/PLM/MES 应用、团队培训和 6S 安全 → 预算、部门月报。
7. 协同：参与新项目物流成本、客户物流条款、变更切换、投诉补货与审核 → 评估或确认记录。

### 生产计划主管｜排程审核与异常协调主责

1. 主责：拆解预测及订单，核算工时、产能与物料，编制并审核月/周/日排程 → 排程表。
2. 主责：平衡产线负荷，处理急单/插单/设备故障，发布调整版本并通知相关部门 → 排程变更记录。
3. 主责：每日核查各产线进度、工序交接和计划偏差，组织周例会、追踪整改 → 进度报表、异常台账。
4. 主责：审核半成品和辅料需求，提前排查缺料，与采购/仓库确认到货与齐套 → 物料需求计划、缺料预警。
5. 主责：测算产能利用率、存货周转天数、在制品及呆滞品，提出改善方案 → 产能/库存分析。
6. 主责：汇总计划物流月报和 KPI，分配计划团队任务并向经理升级决策事项 → 月报、任务清单。
7. 协同：支持客户补货、复制模投产、新项目样品、审核及变更切换 → 节点确认记录。

### 计划员｜计划编制、工单下达与每日进度执行

1. 执行：核对订单、预测、库存、BOM 和可用产能，编制主计划、周/日计划及工序排程 → 计划版本。
2. 执行：按批准计划下达生产工单与领料指令，确认车间接收 → 工单、领料记录。
3. 执行：计算物料净需求，提交采购申请，跟踪到货、质检与齐套 → 需求清单、缺料明细。
4. 执行：每日记录产量、进度、合格率与偏差，提报设备、质量、人员和物料异常 → 进度报表、异常单。
5. 执行：维护 ERP/WMS/PLM/MES 中与计划、工单、物料有关的数据，统计计划达成等 KPI → 系统数据、周报。
6. 执行：安排并跟踪国内发运、回单、到达时间，协调运输路线和费用信息 → 发运清单、回单状态。
7. 协同：对急单、设变、库存异常提出调整建议，主管批准后发布执行 → 调整申请与通知。

### 仓库主管｜仓储运营、账实准确与安全主责

1. 主责：落实已批准的库区、库位及设备方案，制定收发存盘现场 SOP，反馈布局与系统指令问题 → 仓储制度、库位实施图。
2. 主责：审核入库/出库单据与异常处置，监督验收、FIFO、拣货、包装、发货 → 审核记录、异常台账。
3. 主责：建立库存台账与超储/呆滞预警，组织日循环盘、月全盘和差异整改 → 盘点报告。
4. 主责：安排人员、班次、培训和考核，检查作业效率与数据及时性 → 排班、培训记录。
5. 主责：检查消防、叉车、货架、扫码枪与现场安全，组织隐患整改 → 点检/整改台账。
6. 主责：汇总库存、出入库、损耗和设备状态，向计划物流经理报告 → 仓储日报/月报。
7. 协同：与采购确认到货、与生产确认领料、与销售确认发货、与财务核对库存 → 交接与对账记录。

### 贵重物品主管｜刀具、夹具、备件专库主责

1. 主责：建立贵重物品编码、保管、防护、双人复核和追溯规则 → 专库 SOP。
2. 主责：核对入库实物、数量、规格和质量，指定库位并同步入账 → 入库记录。
3. 主责：安排防盗、防潮、防锈、防静电巡检，异常即时处置 → 巡检与异常记录。
4. 主责：审核领用单并双人复核出库，核对系统扣账 → 出库/领用记录。
5. 主责：安排专库人员、6S、工装与设备点检，汇总日报、盘点和合规资料 → 专库报表。

### 仓库组长｜班组作业调度与现场复核

1. 执行：依据到货、生产领料和发货任务安排仓管员班次与任务 → 班组任务表。
2. 主责：现场复核入库验收、系统入账、上架和出库拣货、包装、交接是否按 SOP 完成 → 作业复核记录。
3. 主责：安排日抽盘、周复盘、月全盘，收集差异并上报仓库主管 → 盘点差异清单。
4. 主责：检查账物卡一致、库存异常和库区定置、6S、安全作业 → 巡检记录。
5. 协同：对接生产、采购、质量、财务的现场问题，整理效率及异常数据 → 班组日报。

### 仓库统计文员｜单据与库存数据主责

1. 执行：核对收发、调拨、退库单据的字段与审批完整性，当日录入 ERP/WMS → 单据录入记录。
2. 执行：每日核对系统库存、单据与仓管实物反馈，标记异常 → 库存差异清单。
3. 执行：维护电子/纸质台账，按月与财务对账并跟踪差异 → 对账表。
4. 执行：制作出入库、库存、呆滞料、效率及盘点报表 → 日/周/月报。
5. 执行：盘点数据录入、差异汇总，归档仓储单据与合同 → 盘点底稿、档案目录。
6. 协同：向采购、生产、质量、财务提供已核对数据；协助考勤、会议和物资申领 → 查询记录。

### 仓管员｜实物收发存盘执行

1. 执行：核对到货单、数量、外观和标识，异常隔离上报，扫码入账并按库位上架 → 入库单。
2. 执行：按生产/发货单拣货、复核型号与批次、标识并备货 → 拣货单。
3. 执行：核对出库手续，完成扫码扣账、实物交接和签收 → 出库/交接记录。
4. 执行：日抽盘、月全盘，记录盘盈盘亏并上报，不自行调整账面 → 盘点记录。
5. 执行：落实分类存放、FIFO、防潮防尘、库位标识和 6S → 库位状态。
6. 协同：配合统计文员核对单据与账务，发现安全隐患立即上报 → 异常反馈。

### 叉车工｜装卸搬运与叉车安全执行

1. 执行：出车前检查刹车、轮胎、灯光、油/电量并登记 → 点检记录。
2. 执行：按仓管指令完成装卸、转库、备货搬运和规范堆码 → 搬运任务记录。
3. 执行：核对目标库位，摆放稳固且标识可见 → 库位交接结果。
4. 执行：遵守限速、载重和行人避让规则；设备故障或物料异常立即停工上报 → 异常记录。
5. 执行：完成叉车清洁、停放、充电/加油与定期保养配合 → 保养及 6S 记录。

### 刀具管理员｜刀具台账、领用与报废执行

1. 执行：核对采购单、刀具实物与质量，登记编码和入库信息 → 刀具入库记录。
2. 执行：凭已批准领用单核对规格、数量并发放 → 领用记录。
3. 执行：登记库存、定置摆放、执行先进先出与安全库存预警 → 刀具台账。
4. 执行：按流程提交报废鉴定和审批，获批后处置销账 → 报废闭环记录。
5. 执行：日抽盘、月盘点，整理差异、单据与报表 → 盘点/归档资料。

### 打包工｜成品包装与发货准备执行

1. 执行：核对发货单上的型号、数量、外观，发现异常暂停并上报 → 包装前核对记录。
2. 执行：按包装工艺完成防护、封装、缠膜固定 → 已包装成品。
3. 执行：粘贴标签、唛头、追溯标识并核对信息 → 标签核对结果。
4. 执行：按规定码垛、检查托盘稳固性，配合仓管装车交接 → 发货待装区货物。
5. 执行：按需领用耗材，维护作业区 6S 与安全 → 耗材记录、现场状态。

### 驾驶员｜货物运输与车辆安全执行

1. 执行：按调度核对货物清单、数量和包装，装车后固定并采取防雨/防震措施 → 装车确认。
2. 执行：按路线安全驾驶，途中报告位置、路况和预计到达时间 → 运输状态记录。
3. 执行：到货后与收货人清点、签收并取回回单；货损/差异即时取证 → 签收回单、异常证据。
4. 执行：完成出车前、途中、收车后三检，跟进保养、维修、年检和保险 → 车辆点检/维护记录。
5. 执行：登记里程、油耗、通行及进仓费用，提交票据 → 行车日志、费用凭证。
6. 执行：事故、故障、拥堵时保护现场并立即上报，配合调度重新安排交付 → 应急记录。

## 六、需要确认的原始 JD 问题

1. 信息部的 OA 运维和桌面运维工作表缺少实质工作动作；桌面运维岗位字段为空。不能把常见 IT 支持工作直接视作已批准职责。

3. 采购主管工作表大量复用采购总监职责。此稿结合其岗位概述与旧版“采购主管”表，将“集团战略制定”归总监、“子公司执行监督”归主管，属于待管理者确认的边界建议。
4. 计划员 JD 将“战略规划”列为战略级，但实际动作为订单交付执行；此稿按执行岗划分。计划物流经理与生产计划主管对年度目标、产能和排程有重叠，本稿按“经理定策略与审批、主管审核与协调、计划员编制执行”划分。
5. 工业工程部高级经理与助理的原表对标准 C/T 数据有交叉；本稿按“经理核定口径、助理采集和汇总”划分。
6. 物流规划为讨论中的拟设岗位；现有 JD 把场地、运输、包装和系统应用分散在计划物流经理、计划员、仓库主管等岗位，尚无单一岗位对实物流设计及动态数字指令的效果负责。
