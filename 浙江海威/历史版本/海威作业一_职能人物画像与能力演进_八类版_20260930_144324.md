# 作业一｜各职能人物画像与能力演进

> 配套《海威作业一_五页PPT文本稿.md》。这里的“人员”指岗位画像，不代表新增编制。P1—P5 分别对应 0～6 个月、6～12 个月、1～2 年、2～3 年、3 年后。P5 以数据质量、平台稳定性、业务覆盖和人员成熟为前提。

## 一张图看能力如何生长

```mermaid
flowchart LR
  A[原有人员与岗位能力盘点] --> B[P1 进入现场\n建立计划—实物流—数据闭环]
  B --> C[P2 能解释业务规则、系统动作、经营结果]
  C --> D[P3 把方法沉淀成可复制标准]
  D --> E[P4 到基地执行、带教并反馈]
  E --> F[P5 轮换晋升；共性能力进入数字化平台]
```

**人员发展原则**：先评估、再转型；能力以现场任务和经营结果验证，不以参加培训或取得系统权限替代。集团制定共性规则，基地保留日常执行和现场决策。人员轮换需有交接、接任和晋升通道。

## 1. 集团供应链与数字化负责人

**人物画像**：同时理解客户交付、产能、库存、实物流、系统和财务结果的业务负责人；能与运营 VP 划清制造执行及资源协调边界，推动跨基地共性能力建设。

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 盘点现状、确定职责与原运作基线；以宁德先导建立计划—执行—反馈机制。 | 从“管理单一业务块”转为管理信息流、实物流和数字化的共同结果。 |
| P2 | 确认收益口径；统筹计划、仓储物流、数字化、体系与 IE 的协作。 | 能证明机制的经营价值，处理职能间的责任冲突。 |
| P3 | 制定跨基地复制条件、统一指标及客户要求边界。 | 从单厂改进转为集团级方法治理。 |
| P4 | 培养派驻骨干；管理基地实线、集团虚线的双重协作。 | 能把集团方法交给基地，而不替代基地日常管理。 |
| P5 | 建立轮换、晋升及平台治理；决定哪些集团供应链工作可由平台承接。 | 建立人才梯队与运营规则，以数字化平台治理集团各制造基地运营。 |

**验证证据**：跨职能问题处理周期、基线与收益核算、各基地共用指标、派驻交接成功率、平台承接后人与系统/平台协同、人员梯队建立。

## 2. 计划人员（集团计划／基地计划）

**人物画像**：对数字强敏感。懂需求、产能、物料、库存、交付与现场约束，能解释计划指令为何可执行、（价值）偏差来自哪里；知道软件功能边界和数据来源。现有信息化人员可经评估转型进入此岗位。

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 进入现场核对（生产）过程动作“节拍、可用时间、实际产出和异常”；形成可追溯的日计划及反馈。 | 从处理系统数据走向理解业务底层逻辑、上下游和价值目标。 |
| P2 | 联动需求、产能、物料与仓储；用真实数据解释计划达成和损失。 | 从“发生产工单”变为“能判断计划是否可执行、是否有经营价值”。 |
| P3 | 沉淀计划规则、数据口径、异常升级和软件配置，可培训其他基地。 | 从个人经验转为可复制的方法，并将此转化为软件工具。 |
| P4 | 集团培养后派驻基地，实线对基地 leader 负责，虚线接受集团方法与指标支持；具备基础软件配置／开发能力。 | 从集团协调者成长为跨基地可落地的业务骨干。 |
| P5 | 国内外基地轮换、带教当地人员；海外回归后进入集团晋升通道：高级计划经理、基地管理或集团供应链经理岗位候选。 | 从单基地执行者成长为全球化计划与人才复制者。 |

**验证证据**：计划可执行率、需求与产能偏差率分析、交付预测、库存变化与预测、异常闭环、派驻交接后业务连续性。

## 3. 仓储／实物流人员（含规划与执行）

**人物画像**：强图像或文字转化为物理场景与动作的能力。既能在现有设施条件环境下改善库位、搬运、配送与作业动作，也能为新基地规划实物流；负责人懂布局、作业方案、人员与设备能力，执行人员懂动作背后的目的和风险。

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 看见现场物料状态与动作风险；明确库位、搬运、配送、异常反馈的责任。 | 从按指令作业转为理解物流规划与（动作）过程要求。 |
| P2 | 基于现有设施条件优化实物流；把移动、等待、损伤、库存占用与体系要求关联。 | 从“事后复盘”转为提前“识别风险”并按权限调整。 |
| P3 | 形成仓储与厂内物流标准；能从零规划新基地“物流运作”流程并验证。 | 从本地经验转为可复制的实物流规划与培训能力。 |
| P4 | 派驻基地并向基地 leader 实线汇报；熟悉集团系统、绩效和现场接口，带教当地团队。 | 从集团执行／规划者转为跨文化、跨基地现场骨干。 |
| P5 | 与国内基地轮换；海外回归后进入集团晋升通道：实物流规划经理。 | 从单点运作转为全球实物流复制与人才培养。 |

**验证证据**：库位与账实准确、物料等待和搬运次数、损伤与报废、配送及时率、物理场景利用率（结合物料运转）、基地交接及带教结果。

## 4. 数字化业务人员

**人物画像**：以现场业务问题和收益为起点定义功能；精通 ERP／MES／WMS / 现场工具的真实用途（具体到每个系统交互点的动作），能识别设备、物料、动作、质量的数字采集点，并把数据交给计划和运营使用。

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 从按 ERP／MES／WMS / 现场工具或系统维护转为驻现场观察、记录需求和数据断点。 | 从“系统管理员”转为“业务问题翻译者”。 |
| P2 | 联合计划与仓储定义功能、使用场景、AI 工具及财务 controlling 口径。 | 能解释每个系统动作服务谁、改变什么过程价值。 |
| P3 | 沉淀业务规则、数据标准、配置模板和验收方法。 | 从做单项需求转为可跨基地复用的产品／业务能力。 |
| P4 | 支持基地上线与运行；把关键物理状态映射进平台，验证 AI 分析与基础决策。 | 能在不同现场条件下维护业务模型和数据质量。 |
| P5 | 与开发集成人员双向轮岗；吸纳供应链体系和 IE，共同设计“全系统＋AI 工具”。 | 从功能提出者成长为懂业务、接口、配置和基本开发的融合型成员。 |

**验证证据**：现场使用率、数据准确率、数据可信度、需求到上线周期、跨基地复用率、业务收益及问题回退能力。

## 5. 开发、集成与系统维护人员

**人物画像**：懂接口、数据模型、测试、部署、安全与维护的工程人员，同时进入现场理解系统动作的物理含义；专业编码能力与 AI 辅助开发结合。

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 保障 U9 等现有系统及接口；实现先导项目必要的数据采集和业务工具。 | 从接受功能清单转为理解物理场景和业务收益。 |
| P2 | 与数字化业务人员共同定义接口、测试、发布及异常处理；支持 1～2 人的开发／集成配置设想。 | 能判断技术方案的运行成本与业务可行性。 |
| P3 | 形成可复用的配置、接口、测试与部署包，支持多基地适配。 | 从单项目交付转为可维护、可复制的工程体系。 |
| P4 | 接入关键现场状态，支持 AI 结果进入真实业务，但保留人工确认和异常回退。 | 能处理软硬接口、数据质量及现场运行可靠性。 |
| P5 | 与数字化业务人员双向轮岗；使用 AI 降低重复编码工作，仍负责架构、验证、稳定性和安全。 | 从专业开发者成长为懂运营的系统与硬件融合型工程成员。 |

**验证证据**：系统可用性、接口错误率、发布回退次数、故障恢复时间、复用比例、外部（软件）供应商依赖度。

## 6. 集团供应链体系人员

**人物画像**：理解客户体系要求（欧、美、日、韩、中，等）、业务控制点、指标合理性与过程证据，并把合规要求转为集团的（不增加无效负担的）供应链业务规则与动作；与计划、基地和数字化共同工作。

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 参与现状盘点与客户要求梳理；正式岗位和职责范围待确定。（预期从计划or仓储人员中选取） | 从文档／审核视角转向实际运营过程。 |
| P2 | 建立集团体系管理职责，支持 VDA 6.8 等相关要求和问题闭环。 | 能把要求映射到业务动作、记录及指标。 |
| P3 | 统一跨基地业务边界、客户要求、过程控制与证据标准。 | 从单次审核支持转为集团标准设计。 |
| P4 | 支持派驻骨干与基地，评价当地执行是否符合集团口径。 | 能处理全球基地差异，判断何处必须统一、何处可本地化。 |
| P5 | 并入数字化业务团队，与 IE 一起把控制点写进流程、规则、提醒和追溯。 | 从人工检查推动者成长为平台内嵌控制的设计者。 |

**验证证据**：关键控制点覆盖、证据完整性、重复录入减少、审核问题闭环、跨基地规则一致性。

## 7. IE 人员（归属待 CEO 讨论）

**人物画像**：贴近一线，测量动作、时间、布局、设备和人机协同；与计划、仓储及数字化人员一起验证更优过程。前期可以项目协作或虚线加入，不预设组织划转。（重点关注视觉模型的发展）

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 进入生产现场，确认损失发生位置、作业动作和真实时间。 | 从桌面规划转为以现场证据设计动作。 |
| P2 | 联合计划、仓储验证线平衡、搬运、吊具及人机配合改善。 | 能把动作改善与时间、质量、成本收益相连。 |
| P3 | 沉淀布局、动作和能力评估方法，用于新基地方案验证。 | 从局部优化转为可复制的工艺／物流协同方法。 |
| P4 | 随基地项目验证现场条件；把关键物理状态和改善结果交给数字化团队。 | 能跨基地适配并定义物理事实的数字化接口。 |
| P5 | 在组织条件成熟时并入数字化业务团队；把精益方法嵌入 AI 工具和过程评价。 | 从现场改善专家成长为数字化过程模型的共建者。 |

**验证证据**：动作与等待时间、线平衡、人员／设备利用、损伤与安全事件、方案实施后实际收益。

## 8. 基地本地执行与接任人员

**人物画像**：由基地 leader 管理的计划、仓储及现场执行人员；熟悉当地客户、法规、语言、班次和实物条件，并遵循集团共性规则。

| 阶段 | 核心能力与承担的工作 | 相比上一阶段新增的能力 |
|---|---|---|
| P1 | 国内先导现场参与数据收集和异常反馈；海外按项目实际进度启动。 | 从被动报数转为提供可信现场事实。 |
| P2 | 使用统一计划、仓储和异常处理流程。 | 能识别偏差并与集团职能协同。 |
| P3 | 在基地独立执行、反馈与验证，参与本地化适配。 | 从接受指导转为承担本地结果。 |
| P4 | 接受集团派驻骨干带教，逐步接手日常业务。 | 从配合派驻变为可独立值守和处理异常。 |
| P5 | 在集团骨干轮换后保持运作连续；优秀人员进入当地负责人或跨基地培养通道。 | 从执行接任者成长为本地管理与全球人才梯队成员。 |

**验证证据**：独立处理异常比例、交付与库存指标、派驻轮换后的运行连续性、带教考核与晋升结果。

## P5 团队设计的边界

“约 5 人融合型数字化团队”是能力验证设想，不是已批准的固定编制；“至少 2 人支持多基地运营与系统运作”应解释为**关键业务与平台能力具有双人备份、轮值和交接能力**，而不是由两个人包办所有基地的现场执行。验证时选择真实功能，由团队完整完成需求、配置／开发、接口、测试、部署、维护和业务验收，并记录供应商参与部分。只有达到数据质量、稳定性和现场使用门槛，才逐步淡化集团内重复的供应链协调岗位。
