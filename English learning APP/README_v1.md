# English Coach — 本地 MVP

面向商务英语听说训练的可运行原型。内含两个预设场景，完成「盲听答题 → 角色扮演 → 确认转写 → 有依据的任务反馈 → 隔天复习」闭环。

## 运行

在此目录执行 `python3 -m http.server 4173`，然后打开 <http://localhost:4173>。无需安装依赖或配置 API 密钥。可安装为 PWA；离线使用需先在线打开一次。

## 当前边界

- 听力和对方发言使用随应用提供的固定英文音频，避免浏览器选择不合适的系统语音；这仍是合成语音。听力播放失败时可切换阅读模式，该结果不计入首次听力正确率。
- 角色扮演由预设对话驱动。浏览器支持时可语音输入，否则可打字。转写必须由用户确认。
- 反馈只检查任务要点和表达线索，不评判发音或英语等级，也不把语音识别结果直接视为错误。
- 练习记录存于 `localStorage`，本应用不保存音频。浏览器语音识别可能调用浏览器或系统服务处理语音；若不愿使用，可直接打字。清除浏览器数据会删除记录；可在设置中导出或删除。

音频素材可在 macOS 上运行 `node scripts/generate-audio.mjs` 重新生成，需安装 `ffmpeg` 并允许系统语音服务。脚本会拒绝空音频文件。
