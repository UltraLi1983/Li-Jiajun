# 音频异常排查记录

- **现象**：用户反馈朗读声音奇怪。
- **根因**：原实现调用浏览器 `speechSynthesis` 且未指定语音包，并把 `Maya:` 等说话人姓名交给 TTS 朗读。浏览器语音包和支持程度不一致；本次应用内浏览器未暴露该接口。
- **修复**：用 macOS 系统语音预生成两个场景的双人对话及六条角色提示，做音量归一化后由应用统一播放本地 `.m4a`；说话人姓名不在语音文本中。添加正常、慢速、稍快三档，完整播放后才可提交听力答案。
- **验证**：8 个音频文件均有有效时长（对话约 23–33 秒，角色提示约 4–5 秒）；`node --test test/audio.test.mjs` 通过；应用内浏览器显示新控件并成功触发播放。未能通过自动化判断人耳主观音质，需用户试听确认。
- **注意**：系统语音仍属于合成语音。受沙盒限制时 `say` 可能产生空文件，生成脚本现会报错并拒绝该文件。
- **状态**：DONE_WITH_CONCERNS（主观音质待用户试听）。
