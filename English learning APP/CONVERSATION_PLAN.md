# AI 对话版的首轮验证

## 要验证什么

学习者是否愿意每周多次进入贴近本职工作的英文对话，以及复盘是否能帮助下一次把沟通任务完成得更好。首版关注真实语境、自然接话和有证据的反馈；不推断英语等级。

## 已实现的闭环

选择或输入情境 → AI 创建具体情节并开场 → 轮流语音/文字沟通 → 核对转写 → 最多三条重点反馈。

## 试用时观察

- 用户是否能在 5–10 分钟内完成一次有目标的对话。
- AI 是否保持业务角色、根据用户回答追问，而不是突然变成老师。
- 语音识别错误的比例和用户修正次数。
- 反馈引用是否逐字存在于确认后的用户表达，改写是否真的更自然或更准确。
- 单次训练的 API 用量、连接失败率和中断率。

## 下一步

先用真实 API 账户和 3–5 段试用对话验证语音质量与费用，再决定是否加入历史记录、间隔复习及更多场景。由于当前环境没有 API 密钥，真实服务联通与主观教学质量仍需实际试听和复核。
