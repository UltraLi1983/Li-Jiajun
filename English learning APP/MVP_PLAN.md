# English Coach 首版实施方案

此文档把 [原始 PRD](Personal_AI_English_Coach_PRD_v1.md) 收敛为可验证的首版。首要问题是：汽车供应链或国际商务学习者，能否在连续两周内愿意重复使用这个训练闭环，并能在相似工作任务中更完整地表达关键事项。

## 目标用户与使用场景

- 首批用户：B1–B2 水平、需要在英文会议和供应商沟通中听懂信息并推进事项的中文母语职场人士。
- 主要情境：供应商交付延期、项目需求变更。每轮训练约 12–15 分钟；等内容和交互稳定后再扩至 30 分钟。
- 设备：先用桌面或手机浏览器。训练记录先保存在当前设备，不做跨设备同步。

## 首版闭环

1. **听力**：播放短对话；先作答，再显示原文和正确答案。记录播放次数，重播后的结果不当作严格首次听力分数。
2. **角色扮演**：预设三轮对方发言；学习者语音输入或打字。每轮提交前可修正转写。
3. **任务反馈**：仅用确认后的文字检查是否提到事先定义的沟通要点，显示对应原句、缺失项和参考表达，最多展示三条待补充项。此阶段不评发音、语法或 CEFR 水平。
4. **复述与复习**：当场可复述；缺失要点隔天进入新语境复习。学习者标记“能独立表达”或“还需练习”，决定下次出现时间。
5. **记录与隐私**：显示完成次数、听力正确率、任务要点覆盖率；可导出或删除本地数据；应用不保存音频。

## 当前交付状态

本仓库已提供不依赖外部 API 的可运行原型。它能验证流程与交互，但预设对话和关键词判断不能验证 AI 教练效果。浏览器语音合成/识别的支持程度与质量因设备而异，语音识别可能调用浏览器或系统服务处理音频。

## 下一轮开发顺序

| 顺序 | 交付 | 完成判据 |
| --- | --- | --- |
| 1 | 5–10 个经过人工校对的场景 | 每个场景有明确任务、听力答案、对话分支和反馈要点；试用者能独立完成。 |
| 2 | 服务端语音与模型适配器 | 密钥只在服务端；失败可重试；保留原始转写、修正后文字和反馈证据。 |
| 3 | 人工核查反馈质量 | 抽样 50 次回复，记录误判、漏判和无依据反馈；出现无依据结论时不展示评分。 |
| 4 | 独立测评题库 | 测评材料不出现在训练中；同难度变体与固定评分规则。 |
| 5 | 两周小规模试用 | 观察完成率、重复使用率、语音失败率、每次成本和用户访谈。 |

## 暂缓项目

实时全双工通话、多角色会议、文档导入、跨设备同步、原生 iOS、自动 CEFR 评级。它们需要先证明核心训练有用，再决定投入。

## 试用指标

- 激活：开始训练的用户中，完成首轮的人数比例。
- 留存：首轮完成者中，7 天内完成至少 3 轮的人数比例。
- 质量：反馈中有原句证据的比例，以及人工复核的误判/漏判率。
- 稳定性：语音输入失败率、转写修正率、训练中断率。
- 成本：接入服务端模型后记录每次完成训练的 STT/TTS/模型费用。

## 待决策

正式版首发设备（Mac/手机）、可接受的每月服务成本、是否允许浏览器/云端语音处理、是否需要跨设备同步。当前原型默认优先验证桌面浏览器体验和训练流程。
